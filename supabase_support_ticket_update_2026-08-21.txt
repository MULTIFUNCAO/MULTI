- User ran the script in the SQL Editor and reported it ran clean, no visible error.

- We (the assistant, via the project's own tooling, not a human) verified independently ~1-2 minutes later using the PostgREST REST API with the project's anon/publishable key:

  - Re-checked `usuarios.modelo_cobranca` again ~60 seconds later — same `42703` error, no change.

- We have NOT re-run the migration a second time, per the pattern already established in this project's history with your team (re-running the same statement doesn't fix a revert and just adds noise to the investigation).
